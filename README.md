# Personal Repository for EPI207
*EPI 207: Reproducibility in Epidemiological Research*

---------
## Project3 Folder
Contains code from Project 3 that attempts to reproduce another group's analysis of the association between visiting a doctor and visiting the emergency room (ER) in the past 12 months among California adults, using the 2025 California Health Interview Survey (CHIS) Adult Public Use File. The SAS code reproduces Table 1 (participant characteristics by doctor visit) and Table 2 (crude and adjusted survey-weighted odds ratios using jackknife replicate weights). 

## Project2 Folder
Contains code from Project 2, which examines the association between low household income (below 200% of the federal poverty level) and current use of non-cigarette tobacco and nicotine products, including electronic vaping products, among California adults aged 18-29, using pooled California Health Survey (CHIS) data from 2021-2025. 

## Project1 Folder
Contains Code from Project 1, which was a group project in which we reproduced the results from the paper "Soda Consumption and Hospital Admissions among Californian Adults with Asthma” (Cisneros et al., 2017). This paper utilized data from the 2011 and 2012 cycles of the California Health Interview Survey (CHIS).
